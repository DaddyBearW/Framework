# Sprint Ledger

Консольный сервис учета проектов, спринтов, задач и результатов спринтов.

## Назначение

Приложение помогает небольшой команде хранить проекты, планировать спринты,
учитывать задачи и фиксировать итоги завершенной работы.

## Целевая аудитория

Небольшие команды разработки и студенты, которым нужен простой учет хода
спринтов без отдельной системы управления проектами.

## Предметная область и сущности

- `Project` — проект с названием и описанием.
- `Sprint` — спринт проекта с датами начала и окончания.
- `Task` — задача спринта со статусом `planned`, `in_progress` или `done`.
- `Result` — зафиксированный итог спринта с кратким описанием и числом
  выполненных и оставшихся задач.

Спринт хранит ссылку на объект проекта, задача — на спринт, результат — на
спринт. При сохранении JSON записывает идентификаторы связей, а при загрузке
восстанавливает ссылки на объекты.

| Класс | Основные атрибуты | Методы |
| --- | --- | --- |
| `Project` | `id`, `name`, `description` | `__str__()` |
| `Sprint` | `id`, `project`, `name`, `start_date`, `end_date`, `tasks`, `results` | `__str__()` |
| `Task` | `id`, `sprint`, `title`, `description`, `status` | `complete()`, `__str__()` |
| `Result` | `id`, `sprint`, `summary`, `completed_tasks`, `unfinished_tasks`, `recorded_at` | `__str__()` |

## Возможности

- Создание и просмотр проектов, поиск по названию и сортировка.
- Создание спринтов и задач.
- Просмотр задач и перевод задачи в статус `done`.
- Подсчет статистики спринта и сохранение его результата.
- Загрузка данных при запуске и сохранение изменений в JSON.

## Структура проекта

```text
.
├── main.py           # консольное меню
├── models.py         # Project, Sprint, Task, Result
├── operations.py     # операции над объектами и коллекциями
├── storage.py        # чтение и запись JSON
├── utils.py          # безопасный ввод
├── data/             # projects.json, sprints.json, tasks.json, results.json
└── tests/            # автоматические тесты
```

JSON хранит ID связанных объектов. При загрузке приложение создает проекты,
затем спринты, задачи и результаты, восстанавливая ссылки на соответствующие
объекты.

## Запуск

Требуется Python 3.10 или новее.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```
